# OrangePic

A free iOS, iPadOS, tvOS and watchOS client for your self-hosted [PhotoPrism](https://www.photoprism.app/) server.

[![Download on the App Store](https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg)](https://apps.apple.com/us/app/orangepic/id6751334646)

> This repository is the public feedback page for OrangePic. The app itself is closed source. Bug reports, ideas and questions are all welcome here.

## Features

- Browse all photos and albums from your PhotoPrism server and view photo metadata
- Run PhotoPrism actions from the app: favorite, archive, delete, review, restore and more
- Create, edit and delete albums, add photos to albums and remove them
- Share photos to other apps (Messages, Photos, Files and so on)
- Sort photos by newest/oldest, date added, size and other conditions
- Upload photos and automatic upload of new photos (AutoSync) from iPhone and iPad
- iPhone widget showing latest, favorite or random photos
- Apple Watch app with a synced photo list
- Apple TV app
- Languages: English, Japanese, Korean

All features are available without a subscription.

## Requirements

- A running PhotoPrism server that you control
- The server can be reachable over **HTTPS** and also **HTTP**
